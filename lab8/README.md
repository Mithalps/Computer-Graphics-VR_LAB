# Lab 8 – 2D Transformations

## Objective
To implement 2D geometric transformations: translation, rotation, scaling, reflection, and shearing.

## Tools
- Unity 6
- C#

## Implementation
The project demonstrates transformations using transformation matrices and displays the original and transformed triangles.

## How to Run
1. Open the Unity project.
2. Open the `Experiment8` scene.
3. Press Play.
4. Select a transformation, enter the parameters, and click Apply Transformation.

## Transformations
- Translation
- Rotation
- Scaling
- Reflection
- Shearing
